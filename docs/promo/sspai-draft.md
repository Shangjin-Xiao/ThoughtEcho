## 正文

### 一、笔记应用越来越强，存一句话却越来越麻烦

我手机相册里有几百张截图，全是为了存一句话。

看到一段喜欢的文字，截图。想着以后再整理。然后就没有然后了——相册按时间排列，图片不能搜索，三个月后你连自己为什么截它都想不起来。

按理说这个需求早该被解决了。笔记应用这些年进化得非常快：双向链接、数据库视图、模板系统、块引用。但这些能力服务的是"建构"——你要写一篇东西、管一个项目、维护一套知识体系。

而"我看到一句话，想把它留下来"，是另一件事。它的特点是：

- **发生在别处**。你在微信读书里、在公众号里、在某人的朋友圈里，不在笔记应用里。
- **不能打断**。你正在读东西，任何超过两秒的操作都会让你放弃。
- **当下不需要整理**。你不知道它以后有什么用，你只是不想让它溜走。

用重型笔记应用做这件事，就像用单反拍发票。不是不行，是每次都要下决心。

于是大部分人退回到截图，或者微信"文件传输助手"。

**心迹**（ThoughtEcho）想解决的就是这一件事：让"存下一句话"这个动作，成本低到不需要下决心。

### 二、摘录和笔记，是两种不同的动作

先说清楚定位：心迹不是要取代 Obsidian 或 Notion。它们解决的是建构问题，心迹解决的是捕获问题。

具体到设计上，这个区分带来三个决定：

**第一，入口不在应用里，在系统里。**

心迹在 Android 上注册了系统级的文字处理入口。你在任何应用里选中一段文字，长按弹出的菜单里就有心迹。点一下，这句话就进去了，整个过程不离开你正在读的东西。

这是我认为它最有价值的一个设计。不需要切应用、不需要复制粘贴、不需要找"新建笔记"按钮。

**第二，上下文自动补齐。**

摘录存进来的时候，会自动附上时间、地点和当时的天气。

这个设计一开始我觉得没什么用，用了一段时间才明白：**摘录的价值有一半在"你当时为什么会被它打动"，而这个信息你事后一定想不起来。** 时间地点是最廉价的线索，但它确实能把你拉回当时的状态。

**第三，给一个不用动脑的入口。**

首页每天推一句话，来源可以自己选——一言、ZenQuotes、名言教えるよ 等几个源都支持，也能按分类过滤。喜欢就双击存下，不喜欢划走。

这个功能听起来很轻，但它解决的是"空白页恐惧"。一个空的笔记应用会让人不知道从哪开始；一个每天递给你一句话的应用，你至少有个由头打开它。

### 三、AI 应该做什么，不应该做什么

现在每个笔记应用都有 AI。大部分做的是同一件事：读你的笔记，然后给你一段总结。

我觉得这个方向有问题。总结是只读的——它生成一段新文字放在旁边，你的笔记还是原来那堆碎片。下次你还得再总结一遍。

心迹里的 AI 叫 Thoughter，它做的是另一件事：**它会读你的笔记，然后主动提议修改。**

比如它读完会说"这三条讲的是同一件事，要不要合并"，或者"这条加个标签更好找"。它给出的是一张提案卡，你点采纳，笔记就真的改了；你不点，什么都不会发生。

这个差别听起来小，实际差很多：**总结是产出一份新东西，提议是改进你已有的东西。** 后者才会让你的笔记库随时间变好，而不是越堆越乱。

它也能搜网页、读网页，在需要背景信息的时候自己去查。

几个实际的说明：

- AI 需要自己配 API key。应用内置了十几个服务商的模板（OpenAI、DeepSeek、智谱、硅基流动、Gemini、OpenRouter 等），也支持本地的 Ollama 和 LM Studio。默认推荐的那个有免费额度，注册完把 key 粘进去就行。
- **不配 key 也能用**，只是没有 AI 那部分。摘录、每日一言、富文本编辑、同步、导出都不受影响。
- Thoughter 目前标注为实验性功能，还在打磨。

### 四、本地优先，以及它的代价

心迹没有账号系统。打开就能写，没有登录页，没有"正在同步"。所有数据存在你自己的设备上。

这不是营销话术，是一个有代价的取舍。代价是：**跨设备同步这件事，得你自己动手。**

它给了两条路：

- **局域网直传**：两台设备连同一个 Wi-Fi，基于 LocalSend 协议直接传，不经过任何服务器。
- **WebDAV**：接自己的网盘，带冲突隔离和移动流量开关。目前是 Beta。

比起"登录即同步"当然麻烦。但换来的是：你的东西不在别人的服务器上，服务停了你的数据也还在，不用担心哪天开始收订阅费。

配套的还有：API key 存在系统钥匙串里、支持把一部分笔记藏起来用指纹解锁、一键完整备份（流式写 ZIP，笔记多也不会爆内存）、回收站。

遥测方面：错误上报默认关闭，要开需要你自己在设置里同意。

### 五、说点不好的

按惯例，也说说现在的问题：

- **iOS 还没上架 App Store。** 目前只有 Windows 和 Android 能正常安装。iOS 有构建产物但没签名，普通用户用不了。这是最大的短板，在计划中。
- **英文本地化不完整。** 界面里还有中文硬编码没清干净，英文用户会遇到中英混杂的地方。正在修。
- **功能偏多。** 富文本、多媒体、AI 卡片生成、年度报告、智能推送、PDF 导出……对只想摘录的人来说，有些东西是噪音。这是长期迭代堆出来的，需要做减法。
- **WebDAV 同步和 Thoughter 都还是 Beta。** 能用，但建议养成定期备份的习惯（应用内有一键完整备份）。
- **没有 Web 版**，也没有 macOS 和 Linux 版。

## 投稿备注

**为什么这么写：**

1. **开头用"截图存句子"这个场景切入**，而不是"我做了个 App"。少数派读者对后者免疫，对前者有共鸣——几乎每个人相册里都有一堆存句子的截图。
2. **"摘录 ≠ 笔记"是全文论点**，这是与 flomo / Obsidian / Notion 区隔的关键，也是唯一能立住的差异化叙事。
3. **第三节的 AI 观点是全文最可能被引用的段落。** "总结是只读的，提议才会改进你的笔记库"——这个观点本身有传播力，且是真实的产品差异（多数竞品的 AI 确实只做只读总结）。
4. **第五节如实写缺点。** 少数派读者反感纯吹，主动暴露短板反而提升可信度，且能提前拦掉"iOS 呢"这类评论。
