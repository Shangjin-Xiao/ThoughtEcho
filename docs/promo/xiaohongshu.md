# 小红书文案（5 篇成品）

## 使用说明

**为什么换写法。** 历史两篇各约 3000 浏览、合计 6000 次曝光，但评论主要是"厉害""已 star"——这说明帖子卖的是开发者故事，吸引来的是围观者：会点赞、会 star、不会安装。下面 5 篇全部改成第一人称使用场景，让读者想的是"我也需要这个"，而不是"这个人好厉害"。

**三条硬规则：**

1. **全文不出现开发者个人信息**，叙事一律围绕使用场景展开。
2. **每篇结尾必须有下载引导**，用统一话术（见下）。历史帖最大的浪费就是有人问"求下载链接"却没人接得住。
3. **正文不要放外链**，小红书会限流。链接放主页简介，正文只做口播。

**统一下载话术**（每篇结尾照抄）：

```
🪟 Windows：微软商店直接搜「心迹」就能装
🤖 安卓：主页简介里有下载地址
🍎 iOS：还没上架，在计划了，别急

完全免费，不用注册账号，也没有广告
```

**发布前先做这两件事：**
- 主页简介填上 `note.shangjinyun.cn/dl`
- 每篇发布后，自己在评论区置顶一条：`下载方式在主页简介里～ Windows 直接微软商店搜「心迹」`

**发布节奏**：一周一篇，别一次发完。按下面顺序发，第 1 篇和第 3 篇是最可能爆的。

## 发完之后看什么

**不要看赞数。** 历史两篇 66 赞和 55 赞，转化是 0。

要看的是这条链：**帖子浏览 → `note.shangjinyun.cn/dl` 访问量 → 安装数**。

在 Cloudflare Web Analytics 里按 URL 筛 `/dl`，发帖前后对比。只要 `/dl` 的访问量动了，就说明引导话术起作用了；如果 `/dl` 有访问但安装没动，那问题在下载页本身，回来改页面。
