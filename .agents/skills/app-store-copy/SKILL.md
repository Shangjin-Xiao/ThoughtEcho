# App Store & Marketplace Copywriting

Optimized for mobile app stores (iOS App Store, Google Play, CoolApk, domestic Android stores), balancing App Store Optimization (ASO), readability on mobile screens, and brand tone.

## When to Use
- Preparing App Store / Google Play metadata and promotional text.
- Writing version update notes (What is New / 更新日志).
- Generating short, impactful caption text for app screenshot banners.

## App Store Copy Structure

### 1. Title & Subtitle / Promotional Text (30 characters max)
- Format: `[App Name] - [Core Benefit / Identity]`
- Example: `心迹 - 你的专属灵感摘录本` / `ThoughtEcho - Local-First Thought Journal`

### 2. Promotional Intro (First 3 Lines before "More" button)
- State the primary value proposition immediately.
- Hook the user with the emotional and practical benefit.

### 3. Key Highlights (Bullet Points with Emojis)
- `🎨 纸墨素笺 | 三套手工质感排版，重拾执笔温度`
- `🛡️ 本地优先 | 数据完全归你所有，私有云盘无缝同步`
- `💡 灵感伴侣 | 懂你所想的 Thoughter，让思考更有回响`
- `⚡ 纯净克制 | 无广告、无干扰、打开即写`

### 4. Release Notes ("What is New") Template
- Categorize changes into:
  - ✨ **新功能 (New Features)**: Highlight user benefits.
  - 🎨 **体验优化 (Improvements)**: Smoother interactions, cleaner UI.
  - 🛠️ **问题修复 (Bug Fixes)**: Resolved issues described in user terms.
