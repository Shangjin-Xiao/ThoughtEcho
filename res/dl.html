常见问题 Frequently Asked Questions

安卓安装提示「未知来源应用」？ Android prompt shows "Unknown Source"?

心迹 100% 开源且无任何恶意代码，APK 均直接构建于 GitHub 官方仓库。在系统弹窗中点击「允许安装」或「信任此来源」即可安全使用。 ThoughtEcho is 100% open-source and clean. APKs are built directly on GitHub. Safely tap "Allow" or "Trust source" in your system prompt.

笔记与摘录数据安全吗？ Is my data safe and private?

应用严格遵循本地优先原则。无需注册账号，所有笔记与摘录均存储于设备本地 SQLite 数据库中，绝不未经允许上传。 Local-first by design. No account required. All notes remain in your local SQLite database without unauthorized telemetry.

多设备间如何同步数据？ How to sync across multiple devices?

支持同一 Wi-Fi 下局域网免流量直传，以及通过 WebDAV（如坚果云、Nextcloud 等私有网盘）进行全量或增量加密同步。 Supports zero-traffic LAN direct transfer on the same Wi-Fi, and encrypted incremental sync via WebDAV (Jianguoyun, Nextcloud, etc.).

如何启用 Thoughter AI 伴写功能？ How to enable Thoughter AI features?

在「设置 - AI 助手」中填入您自己的 API Key（支持 DeepSeek、OpenAI、Ollama、Claude 等）。即使不配置 AI，心迹所有笔记与摘录功能亦完全免费可用。 Enter your API Key in Settings (supports DeepSeek, OpenAI, Ollama, Claude, etc.). All core note and excerpt features work 100% free without AI.
