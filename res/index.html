🚀 快速开始 🚀 Quick Start

三步上手 Get Started in 3 Steps

无需注册账号，下载即用 No account needed — download and go

1 下载安装Download & Install

从下载区选择你的平台：Windows 用户推荐微软商店（自动更新），Android 用户可直接下载 APK 安装包。无需注册、无需登录。Pick your platform in the download section: Microsoft Store for Windows (auto-updates), or grab the APK for Android. No sign-up, no login.

2 记下第一条灵感Capture Your First Idea

打开应用点「+」即可记录。支持富文本、图片、音视频，还会自动附上当时的位置与天气。所有数据只存在你的设备上。Open the app and tap "+" to start writing. Rich text, images, audio and video are all supported, with location and weather attached automatically. Everything stays on your device.

3 开启 AI 能力（可选）Enable AI Features (Optional)

不配置 AI 也能完整使用所有笔记功能。想要 AI 问答与洞察报告时，在设置中填入任意服务商的 API Key（支持 OpenAI、DeepSeek、通义千问等，也兼容 Ollama 本地模型，完全免费离线）。All note features work without AI. When you want AI Q&A and insight reports, add any provider's API Key in settings (OpenAI, DeepSeek, Qwen and more — or run Ollama locally, free and offline).
